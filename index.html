My main app

HR Attendance App

When I started in HR, I knew nothing, and I needed better management to finish my work on time. Every day, paper sheets must match fingerprint records, and workers' pay depends on it. Now the app checks them, and I handle the cases that need a person.

My real app · one full day of attendance

13,000+lines of Python

How it earns trust

AI reads handwriting, and unclear values go to a person. Nothing saves until HR types YES.

What real use taught me

232 of 441 night shifts in one week ended near 06:00, not 03:30. So I changed my rules.

Real app, shown with sample workers because real worker data is private. The live app may take a minute to wake up. AI coding tools, mainly Claude, wrote much of the code. I find the problem, set the rules, test it and decide what is right.

Final-year project

Sara, Voice for Excel

My first app. Excel is hard when you must remember formulas and formats, so with Sara you just say what you want. These are real recordings: I speak, Sara changes the real Excel file and answers. A validator checks every action, and undo is built in.

IELTS Study App

When I prepared for my exam, I could not find a free app with the practice and features I needed, so I built it. It has 2,560 questions and 979 key words with Khmer meanings. Book text is blurred here because it is copyrighted.
